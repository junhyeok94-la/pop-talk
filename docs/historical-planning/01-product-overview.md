# 서비스 기획

## 1. 서비스 개요

서비스명은 **팝콘 챌린지(Popcorn Challenge)** 입니다.

> 자체 커뮤니티에 쌓인 영화 평점과 리뷰를 SQL 및 Vector RAG로 분석하고, 사용자의 질문 의도와 취향에 맞는 영화 정보·커뮤니티 반응·추천 결과를 제공하는 영화 커뮤니티 서비스

교육과정의 팀 프로젝트로서 기능 구현뿐 아니라 Web, WAS, AI Backend, Batch를 분리한 서비스 구조와 Naver Cloud 배포까지 시연하는 것을 목표로 합니다.

## 2. 해결하려는 문제

- 영화 기본 정보와 실제 사용자 반응이 여러 서비스에 분산되어 있습니다.
- 평점처럼 정확한 숫자가 필요한 질문과 리뷰 요약처럼 의미 분석이 필요한 질문은 처리 방식이 다릅니다.
- 일반 LLM 답변은 최신성이나 근거가 부족할 수 있습니다.
- 영화 추천 결과가 어떤 데이터에 근거했는지 확인하기 어렵습니다.

팝콘 챌린지는 구조화 데이터, 커뮤니티 데이터와 외부 API를 질문 목적에 맞게 선택하여 이 문제를 해결합니다.

## 3. 목표 사용자

- 영화를 찾고 비교하려는 사용자
- 영화 관람 후 평점과 리뷰를 공유하려는 사용자
- 스포일러를 피하면서 커뮤니티 반응을 알고 싶은 사용자
- 자신의 취향과 비슷한 영화를 추천받고 싶은 사용자
- 콘텐츠와 사용자 활동을 관리하는 운영자

## 4. 핵심 기능

### 영화 탐색

- 영화 목록 및 상세정보 조회
- 영화명, 장르, 감독, 배우 등의 조건 검색
- 외부 API를 이용한 최신 영화 정보 보완

### 커뮤니티

- 회원가입과 로그인
- 영화 평점 및 리뷰 작성·수정·삭제
- 댓글, 좋아요와 신고 등 사용자 상호작용
- 스포일러 표시와 공개 상태 관리

### AI 영화 질의

- 영화 기본정보 조회
- 커뮤니티 평균 평점과 평가자 수 조회
- 공개 리뷰의 공통 의견 요약
- 스포일러 제외 리뷰 분석
- 장르, 배우, 국가와 사용자 취향을 반영한 추천
- 대화 맥락을 유지하는 후속 질문

### 배치 처리

- 외부 영화 데이터 동기화
- 리뷰 및 영화 임베딩 작업
- 실패 작업 재처리와 데이터 정합성 점검

### 팝콘 챌린지

서비스 정체성을 나타내는 챌린지 기능의 상세 규칙은 팀 합의 후 확정합니다. 예를 들어 기간별 영화 감상 목표, 장르별 도전, 리뷰 작성 미션 등을 후보로 검토할 수 있으나 현재 확정 기능은 아닙니다.

## 5. 대표 사용자 시나리오

### 정확한 평점 조회

사용자가 “듄: 파트 2의 커뮤니티 평점은 몇 점이야?”라고 물으면 PostgreSQL에서 평균 평점과 평가자 수를 계산한 뒤 답변합니다.

### 스포일러 없는 리뷰 요약

사용자가 영화의 아쉬운 점을 물으면 영화와 질문 의도를 식별하고, 공개 상태이며 스포일러가 없는 리뷰만 Vector 검색한 뒤 검색 결과를 요약합니다.

### 평점과 리뷰의 결합

평점처럼 정확한 값은 SQL로, 호불호의 이유처럼 의미 분석이 필요한 내용은 Vector 검색으로 처리한 다음 하나의 답변으로 통합합니다.

### 최신 영화 조회

현재 상영작처럼 최신성이 중요한 질문은 오래된 임베딩보다 외부 Open API 또는 주기적으로 갱신한 DB를 우선 사용합니다.

## 6. 데이터 처리 원칙

| 데이터 또는 질문 | 처리 방법 |
|---|---|
| 평균 평점, 리뷰 수, 좋아요 수 | PostgreSQL SQL |
| 영화명, 감독, 배우, 개봉일 | PostgreSQL 또는 영화 Open API |
| 리뷰의 공통 의견 | pgvector 검색과 RAG |
| 사용자 취향 추천 | 평가 이력, 추천 로직과 필요 시 RAG |
| 현재 상영 정보 | 최신 Open API 또는 동기화 DB |
| 회원, 권한, 인증 | 일반 애플리케이션 로직 |

다음 원칙을 공통 기준으로 사용합니다.

1. 정확한 숫자는 SQL로 계산합니다.
2. 긴 텍스트의 의미 검색에만 Vector 검색을 사용합니다.
3. 최신 정보는 외부 API 또는 최신 동기화 데이터를 사용합니다.
4. AI Backend에 운영 DB 임의 SQL 권한을 주지 않고 제한된 조회 기능을 제공합니다.
5. 답변에는 가능한 범위에서 근거, 리뷰 수, 기준 시각과 스포일러 포함 여부를 표시합니다.

## 7. MVP 범위

- 회원 인증
- 영화 목록·검색·상세
- 평점과 리뷰 작성
- 영화 정보, 평점, 리뷰 요약 및 추천 AI 질의
- 외부 영화 데이터 동기화
- 기본 관리자 조회
- Naver Cloud 환경 배포와 시연

실시간 좌석 예매, 결제, 복잡한 소셜 기능과 고도화된 추천 모델은 MVP 이후 범위로 둡니다.

## 8. 결정이 필요한 항목

- 챌린지의 종류, 달성 조건과 보상 정책
- 실제 프런트엔드 프레임워크와 UI 디자인 시스템
- WAS의 프레임워크 및 인증 방식
- AI Backend와 WAS 사이의 API 계약
- Open API 공급자와 호출 제한 대응 정책
- 콘텐츠 신고·차단 및 관리자 운영 정책
